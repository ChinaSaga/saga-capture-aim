# CAT 与 MAKCU 统一控制

主窗口右上方新增 **CAT 网络盒子** 按钮。在同一个窗口输入 IPv4 地址、端口（1～65535）和 8 位十六进制 UUID，点击“保存并连接”。连接在后台完成，窗口顶部显示当前使用的设备。

## 调用协议：CAT 1.2 UDP

当前软件使用 **CAT 1.2 UDP**。盒子控制台的协议列表须将 `libcat_protocol_v1.2_udp.so` 设为当前协议，再重启 CATBOX 服务使其生效。不要选择 `libkm_protocol_v2.0_udp.so`，该协议与当前 CAT SDK 调用不匹配。这里的 1.2 是调用协议版本，与盒子的固件版本分开。

USB/RNDIS 连接时填写盒子端的 IP，不要填电脑网卡的 IP。本次实机盒子地址为 `192.168.7.1`、电脑网卡为 `192.168.7.2`；实际值以各自设备配置为准，端口与 UUID 从盒子设置读取。

- 参数保存在 EXE 目录的 `CAT盒子.ini`，下次启动自动读取。该文件不提交到 Git。
- CAT 完成命令握手和按键监听握手后才启用；CAT 可用时优先，未配置、停用或离线时使用可用的 MAKCU。
- “停用 CAT”保留已保存参数，并切回 MAKCU；“取消”不修改配置、不退出软件。
- CAT 离线后约每 3 秒重试，在线时每秒一次零位移命令检查应答；MAKCU 保留现有自动检测和重连。
- 移动、轨迹测试、按下、松开、瞄准热键和触发热键共用路由。五个鼠标按键保持原有编号：1 左键、2 右键、3 中键、5/6 侧键。
- 网页的自瞄、准星绑定和扳机共 12 个热键选择框支持 104 个键盘选项。键盘绑定使用 `1000 + CAT/Linux input 键码`，与旧鼠标编号分开；左右修饰键分别选择，当前支持单键。由 CAT 上报键盘状态，不读取运行软件电脑的本地键盘。CAT 离线或切回 MAKCU 时，键盘状态返回未按下。网页与新版 EXE 需要一起更新。
- 切换设备前尝试释放软件按下的按键。网络失联时无法保证即时释放，失败的 CAT 松开命令会在恢复连接后重试；移动和按下命令不补发。
- 准星追踪的“测距按下”只提供空白和 CAT 键盘键；空白关闭。任意一组自瞄热键实际按住时，独立线程交替发送所选键的按下/抬起，按住 35～65ms、间隔 55～95ms，带少量随机变化，不积压补发。吸附常驻本身不会触发连按。松开自瞄热键、清空/换键、切换设备及正常退出会释放当前键；断网失败的释放在重连后补发。该项随配置保存/导入，旧配置默认关闭；输出仅使用 CAT，不向本机或 MAKCU 发送键盘事件。

CAT 使用 UDP，命令端口填写盒子的远端端口，本机发送端口和监听端口由系统分配，监听端口会通过协议通知 CAT。需要网络路由可达，并允许应用接收 CAT 的 UDP 报文。不会扫描整个局域网，也不会自动修改防火墙。

CAT 保留原 SDK 的逐命令应答机制，单次命令等待上限为 300ms；正常延迟取决于网络和固件，因此其时延不能视为等同于 MAKCU 串口。轨迹分段保持不变。按 2026-10-13 实机测试及用户要求，MAKCU 保留原有 0.885ms 分段等待，CAT 跳过额外等待、仍逐条等待 ACK；每次移动按实际发送设备决定，回退 MAKCU 后恢复原等待。

验证：Release 构建；`tools/test_box_controller.cpp` 本机加密 UDP 模拟覆盖参数校验、错误 UUID、五键映射、物理按键上报、监听失败后重启、设备切换时释放、命令超时、自动回退、自动恢复和停用。该测试不等同于 CAT 实机兼容性验证，固件实际端口行为和鼠标操作仍需实机检查。

2026-10-13 另完成 CAT 1.2 UDP 实机验证：通信测试 9 组各 1000 次移动全部成功应答；Raw Input 实际位移测试 10 组各 1000 次全部总量一致，其中 4 组额外等待 0 ms，耗时约 250～260ms/组。快速组 Windows 每组接收约 251～262 个原始输入事件，表明位移被合并，不能等同于每条命令独立输出或长期满载保证。测试源码为 `tools/benchmark_cat_latency.cpp`、`tools/benchmark_cat_raw_input.cpp`，读取指定的本地 CAT INI；执行会实际移动鼠标。`tools/cat_move_ten.cpp` 用于连续向右移动 10 次、每次 10 单位的画板观察。
