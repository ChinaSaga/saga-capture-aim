# 维护红线与已知问题

本页保存当前项目仍需要的行为、精度和维护约束，不依赖历史报告或备份。

## 行为与数值约束

| 项目 | 必须保留 |
|---|---|
| 鼠标轨迹分段等待 | MAKCU 0.885 ms；CAT 无额外等待，保留逐条 ACK |
| 分组 | 10 次逐段；5 次按相邻两段；3 次按 0–3 / 4–6 / 7–9 |
| 截图 | JPEG 95、节流 80 ms、新鲜度 125 ms |
| 单帧目标上限 | 99；所有结果写入必须遵守固定数组容量 |
| AimLock | 保留选靶结果、头身关联、阈值和记忆语义 |
| 状态栏推理帧率 | 显示图片时采用实测帧率，不显示时采用 1000/耗时 |
| 内部字符集 | GBK，源码 UTF-8；路径使用 Unicode |
| Release 开关 | 既有 AVX2 / fast FP / LTCG；SDL / GS / CFG 的项目设置保持原值 |

NCNN 灰边的 114/255 必须保留运行时乘法；常量折叠可能造成 1 ULP 差异。ONNX 的 NAS 后处理保留按值语义，不能直接替换为借用版本。训练模块保留 precise FP 和有限值检查。YUV 转换可运行时选择支持的 AVX-512 路径，主程序仍按 AVX2 编译。

## 配置、网页与线程

网页源文件为 `web/圣人视觉识别系统.html`，构建自动复制到 EXE 旁。缺少部署网页时返回“网页不存在”并停用调参，补回后刷新恢复。不能改为加载旧备份或另一个目录的网页。

三套热键始终监听，冲突优先级 1 > 2 > 3；网页标签仅切换编辑对象。吸附常驻选择第 1 组，但测距连按仍要求物理自瞄键按住。补偿幅度 0 关闭，1–100 保持当前连续预测追赶；类别锁定位置、选靶和扳机基于实际检测。

完整设置在锁下发布。移动命令先消费再发送，并检查代次及 125 ms 新鲜度；已发给硬件的命令无法撤回。切换模型、范围或配置时不能发布过期结果。

推理状态、候选数组和目标记忆由各引擎线程独立拥有。帧引用只读，退出使用后及时归还；不能长时间租借满 8 个帧槽。采集生产者锁到快照锁的顺序必须保持一致。不得以忙轮询替代已有条件等待。

诊断通过 `runtime_log` 后台队列批量落盘，业务线程不直接写日志；正常帧和鼠标命令不逐条记录。历史日志可以删除，当前诊断功能保留。

## 易语言数值对齐

- 除号为实数除法；取整为 floor。
- 小数赋给整数变量采用四舍五入，不能改为直接截断。
- 颜色保持既有 BGR 打包规则，检测类别号为 label + 1。
- 循环间需要保持的局部状态不能被误改为每轮清零；跨线程状态也不能误改成共享 static。

## 当前限制与排错

- UDP 只有接收端，沿用 1472 字节分包。已有 BMP/JPEG 边界、16 MiB 上限和来源隔离，但无包序号与校验，不能可靠修复丢包、乱序。本地采集运行时不发布 UDP 帧。
- 鼠标热键只支持 1/2/3/5/6，4 无映射；CAT 键盘另用 1000 + Linux input code。
- NCNN 输入尺寸依赖 `.param` 中可识别的导出信息；模型加载及组内尺寸必须通过校验。GPU 路径的单线程和 FP16/INT8 选项不能凭印象修改。
- CAT 通过 BoxController 接入并优先使用，离线回退 MAKCU；具体协议见 [统一控制](CAT与MAKCU统一控制.md)。
- CH343 的驱动包存在不等于设备可用：需要检查服务、SYS 和串口；安装包含设备更新与重枚举。安装失败可能保留系统临时目录便于排错。
- 线程优化维持当前优先级策略，不擅自设置 CPU 亲和或全局 GPU 锁频。
- 局部基准不能外推为采集卡、推理、鼠标整条链路的性能。

## 保留与清理

当前模型、`人手数据`、人手轨迹原始数据、命名配置、驱动资源、SDK、许可证、源码和测试工具都属于有效项目内容。`.workbuddy` 由工具按需创建；测试输出、旧版本、历史报告和会话记录不是运行依赖。

构建和不接采集卡的验证见 [构建与部署](构建与部署.md)。
