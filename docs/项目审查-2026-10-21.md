# 项目审查与修复（2026-10-21）

本轮检查了应用状态、采集与 UDP 收帧、预览、选靶与移动、HTTP 配置、三个推理入口、模型加载、输入设备封装、文件路径、日志和构建测试脚本。以当前工作区为基础，保留并验证了此前尚未提交的 Unicode 路径修复，以及两个尚未推送的采集/预览提交。未改写 vendored Asio、驱动包和模型文件。

## 修复内容

| 问题 | 处理 |
|---|---|
| HTTP 写配置与多个工作线程直接读写字符串、数值 | 使用 `RuntimeSettingsStore` 发布完整的小型快照；开关改成布尔值，工作循环不再读取可被并发改写的字符串。跨线程统计、尺寸和状态字段改用原子访问。 |
| 移动完成后清零会覆盖发送期间产生的新指令 | 在短临界区内读取并清除待消费指令；设备 I/O 不持该临界区。单独限制同一时刻只有一个移动消费者，移除对显示距离的消费式清零。 |
| 暂停、模型切换、断帧或失去目标后旧指令可能继续执行 | 给推理结果加代次；暂停/模型切换使旧代次失效；恢复时重置旧模型的选靶记忆和 PID。无目标、进入中心停移范围时清除待消费移动；移动和扳机启动前检查采集及对应推理帧的新鲜度（125 ms），避免采集仍在继续时执行已经过期的推理结果。已经发到硬件的命令无法撤回。 |
| HTTP 请求体可绕过原有 64 KiB 检查；不完整请求也可能修改配置 | 统一解析器：头部 16 KiB、请求体 64 KiB；大小写无关的 Content-Length；拒绝重复长度、非法长度、Transfer-Encoding、多余字节和截断请求。接收有总计 5 秒期限，同时最多处理 16 个连接；请求异常由连接线程处理。 |
| 非法配置值、BOM 和文件名边界 | 严格解析数值并处理溢出及 NaN/Inf；BOM 在 UTF-8 转换前移除；拒绝模型/配置名称中的路径分隔符、设备名及控制字符；拒绝未知配置键。GBK 双字节字符中的 `0x5c` 不再被 JSON 转义误伤。 |
| 保存配置直接截断原文件 | 先在同目录写入并刷新临时文件，再原子替换。写入或替换失败保留原文件，并向网页报告错误。 |
| NCNN/ONNX 直接 BGR 推理入口未检查状态、异常可逃逸线程 | 检查模型、输入指针、尺寸及行跨度，并捕获模型加载/解码/推理异常。NCNN 检查输入提交结果、输出存储格式，卸载时释放预处理缓存。 |
| BMP 头部整数乘法及负高度溢出 | 三个引擎共用经过检查的 BMP 视图解析器，使用宽整数计算跨度和字节数，不再通过未对齐类型指针读取头部。 |
| ONNX 多输入模型可能令 Run 读取不存在的输入数组元素 | 加载时限定单个 float32 RGB 图像输入；验证输入维度、输出类型/秩/批次和各后处理分支的形状约束，给不兼容模型返回错误。 |
| UDP 无限累积、不同发送者粘包、本地采集被远端统计覆盖 | 累积限制为 16 MiB；区分来源地址/端口，超时和过长帧丢弃；识别 BMP 声明长度及 JPEG EOI，兼容最后一包也是 1472 字节的情况；本地采集启用后不再发布 UDP 帧。 |
| 计时器首次初始化存在竞争，测试断言被关闭 | QPC 换算常量使用线程安全的一次初始化；测试源码编译时明确开启断言，修复此前未跟进接口变化的退出和预览测试。 |

## 性能与行为范围

本轮减少了工作循环的字符串读取/比较，保留最新帧与预处理缓存的复用方式，清除了卸载 NCNN 后残留的输入缓存。没有改动 AimLock 选靶算法、轨迹分组、MAKCU 0.885 ms 间隔、CAT ACK 规则、99 个目标上限、JPEG 95 或 80 ms 截图节流。未改动 Release 的指令集、浮点及安全检查开关。

没有进行硬件端到端性能对照，因此不声称整体 FPS 或延迟有某个百分比的提升。网络限额、错误处理和配置快照主要改善异常情况下的稳定性。

## 验证

```powershell
./tools/build.ps1
./tools/test_review.ps1
# 需要本机 x64/Release/模型数据 中的三角洲416 NCNN/ONNX，以及人手模型；均不入库。
./tools/test_desktop_paths.ps1 -OutputDirectory .workbuddy/review-desktop
# 使用已有的 jsdom 环境
$env:NODE_PATH = Join-Path $PWD '.workbuddy/web-profile-test/node_modules'
node tools/test_web_profiles.cjs
```

- Release x64 主程序、ONNX 转 TRT 工具构建通过。
- `test_review.ps1` 的 20 个原生测试均开启断言，覆盖网络解析、移动消费、输出形状、配置快照、原子文件保存、采集像素/预览、热键、串口协议、CAT 模拟通信、TensorRT API 边界、FP16 转换、ORT 兼容、进程退出和异步日志。
- 三个网页测试覆盖模型列表与引擎切换、错误提示、完整页面初始化和三组热键配置。
- 桌面路径测试覆盖中文、emoji、超过 MAX_PATH 的目录、默认和 UTF-8 进程代码页；实际加载 NCNN/ONNX/人手模型，并对 NCNN 和 ONNX 各执行 CPU 推理。
- 本轮没有操作实际鼠标盒子、自动安装驱动，也没有完成采集卡到 GPU 到硬件输出的整链实测。

## 仍需现场或协议配合的事项

UDP 旧协议没有帧号、分片序号或校验，接收端不能可靠恢复丢包和乱序；需要发送端一起升级。NCNN 非 pnnx 模型的输入尺寸识别仍有兼容范围限制。GPU 驱动、TensorRT 引擎及实际采集设备组合的稳定性，需要使用目标机器和模型另做长时间实测。本轮审查不能证明所有设备、模型和运行路径均不存在缺陷。

原有 `UI界面/` 素材与 `tools/game-diagnostics/` 现场诊断工具保持在本地，未纳入此次修复提交；运行期配置、模型、构建产物和测试日志仍按仓库规则忽略。
