# 游戏环境诊断与重启

双击 `Report-And-Restart.bat`：先保存诊断报告，然后倒计时 60 秒重启。按 C 取消，按 R 立即重启。请提前保存工作；应用阻止关机时，本工具不强制结束应用。

双击 `Collect-Only.bat`：只收集报告，不重启。普通权限即可收集大部分内容；TPM、安全启动等项目若权限不足，会记录 unavailable，不代表功能已关闭。

报告位于本文件夹的 Reports 子目录。包含进程路径、启动项、硬件标识、EDID 和近期错误日志；仅保存在本机，不上传。分享前检查个人路径及设备标识。

本工具不执行系统清理，不禁用启动项、服务或驱动，不修改 EDID、ACE、注册表或系统安全设置，不保证解决踢下线问题。PowerShell 的 Bypass 仅用于这次进程运行，不持久修改执行策略。它用于留下可比较的诊断证据，避免在原因未明时批量修改系统。

建议对照流程：

1. 记录 ACE 完整提示、错误代码与发生时间；确认工具运行在实际游戏电脑上。
2. 完全退出采集识别和鼠标自动控制程序，断开相关控制外设及采集卡，将显示器直接连接显卡，再运行重启脚本。
3. 重启后只启动官方游戏客户端进行测试。若依旧异常，通过官方客户端校验游戏文件，并向官方客服提供错误信息。
4. 若直连正常，在退出游戏后连接正规录制用采集卡，再启动游戏比较。游戏运行期间不要反复插拔设备进行测试。重新收集报告并记录复现时间。
5. 只有确定具体冲突程序后才禁用其启动项或使用厂商卸载程序卸载。不要批量禁用非微软服务，游戏和 ACE 也可能依赖其中的服务。

热插拔与踢下线同时发生，不能单独证明 EDID 是原因。硬件驱动、显示链路切换和软件冲突均需通过对照测试核实。本工具不能用于隐瞒自动控制程序或绕过反作弊检测。
